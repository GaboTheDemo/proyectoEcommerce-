# coreSystems code of conduct
We will be using GitFlow to update our project, so each time you want to make a change to the project, you'll create a branch depending on what you want to do, give it a category, and a name.

- Feat: A feature is added to the project.
- Style: A .css file is modified.
- File: A file is uploaded.
- Hotfix: For quickly correcting an error in the project.
- Release: For making the final preparations before a release.

## Examples:

feat/main-page
style/change-login-styles
file/added-logo-file
